## Workflow

1. Read the live `opencode run` help and refreshed verbose model catalog before selecting the interface and model.
2. Prefer high or the highest available reasoning level.
3. For a second opinion, critique, explanation, or reasoning-only answer, send an `ask`-mode prompt with the relevant context and exact question,
   explicitly forbidding edits.
