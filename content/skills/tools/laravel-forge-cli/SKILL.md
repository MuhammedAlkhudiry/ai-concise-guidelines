---
name: laravel-forge-cli
description: Laravel Forge CLI operations for install, auth, server switching, deploys, env sync, logs, remote commands, SSH, and resource checks.
---

Run `forge list` and `forge help <command>` for current commands and options. Inspect the installed package metadata and current official sources when version or installation behavior matters.

Confirm the active server before site or resource operations. Treat tokens, environment files, logs, deployment output, and remote command output as sensitive. Prefer the CLI over the Forge API or dashboard.
