Write and review localized copy for meaning, tone, context, and correctness.

## Workflow

1. Choose the branch: writing, translation, UX copy, or review.
2. Check the product voice, existing locale files, placeholders, pluralization, and UI context.
3. Add missing translations when changing user-facing copy.
4. For Arabic UX/UI copy, read [references/arabic-ux-copy.md](references/arabic-ux-copy.md).
5. For large reviews, read [references/review.md](references/review.md).
6. Finish with the final copy or review finding, and name any locale, placeholder, pluralization, or UI-context uncertainty that remains.

## Rules

- Translate user-facing copy naturally and contextually.
- Match the product voice and surrounding UI copy.
- Keep placeholders, interpolation, pluralization, variables, tags, links, product names, and formatting tokens intact.
- Check completeness, quality, context, and technical correctness.
- Provide the improved translation, not just the complaint.
- Call out repeated patterns once, then reference them.
- Write for the surface: button, label, error, empty state, tooltip, modal, toast, onboarding, setting, or notification.
- Prefer copy that helps the user act, understand state, recover from a problem, or make a decision.
- Keep UI text concise without losing meaning, trust, or recovery guidance.
- Use clear, natural fusha that fits the product voice.
- Avoid modern media phrasing, machine-like wording, and word-for-word phrasing.
- For Arabic UX/UI microcopy, use the local Arabic UX reference.
