# Google Cloud

- **Route:** Use `gcloud`; derive current project, API, service-account, and IAM commands from its help.
- **Discover:** Inspect live native authentication and configuration state; native state belongs under `~/.config/gcloud/`.
- **Verify:** Run the smallest read-only project description supported by the installed CLI.
- **Repair:** Use the installed CLI's authentication and configuration help, select the intended project, and enable only the required API. Pause for OAuth or new IAM grants.
