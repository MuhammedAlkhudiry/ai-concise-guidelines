# Verification Toolkit

Use this only when bootstrapping a new project's verification setup or repairing missing setup. If
repo-root `CHECKLIST.md` exists, do not read this file.

Treat these as discovery hints. Confirm availability and commands from the project and installed tool
help.

- Orchestration and runtimes: Mise, Make, Bun, Composer, Herd
- JavaScript and TypeScript: oxfmt, oxlint, TypeScript, tsgo, knip
- PHP and Laravel: Mago, Pest, PHPUnit, PHPStan/Larastan, Rector, composer-unused
- Web: Playwright, Vite
- Mobile: Jest, Maestro, EAS
