---
name: teach
description: Teaching mode when the user asks to understand how something works.
---

## Workflow

1. Start with the real thing the user is looking at: code, docs, runtime evidence, product behavior, or their stated situation.
2. Answer the specific question using only the project names, flows, constraints, evidence, examples, or trade-offs needed to make it clear.
3. Explain step by step only when ideas depend on one another or the user requests more depth; otherwise give the shortest rationale that makes the
   answer understandable.
