# Muhammed's Workflows Privacy Policy

Muhammed's Workflows is a skills-only plugin. It provides instructions to ChatGPT and Codex and does not operate a server, collect data, store user
content, or receive credentials.

The plugin can instruct ChatGPT to use services the user has connected separately, such as GitHub. Those services remain governed by their own
permissions and privacy terms. The plugin does not receive or retain data returned by connected services outside the user's ChatGPT session.

Questions can be submitted through the [project issue tracker](https://github.com/MuhammedAlkhudiry/my-setup/issues).
